# Мини Банк — мобильное приложение

Учебное банковское приложение на React Native (Expo) + TypeScript.
Показывает счета и баланс, переводы между счетами, историю операций с
аналитикой трат и **платёжные QR-коды** по ГОСТ Р 56042-2014 — такие же,
как на квитанциях ЖКХ. Сгенерированные приложением коды распознаёт мой
второй проект — сканер на OpenCV (qr-scanner-opencv).

> Все данные (счета, реквизиты, операции) выдуманные и хранятся в памяти
> приложения. Настоящих денег и сервера нет.

## Экраны

| Экран    | Что умеет |
|----------|-----------|
| Главная  | общий баланс, карточки счетов, быстрые действия, последние операции |
| Перевод  | перевод между своими счетами с проверкой суммы и остатка |
| QR       | **Получить** — QR с реквизитами, суммой и назначением платежа; **Оплатить** — разбор строки из QR и оплата |
| История  | операции по дням, траты за 30 дней по категориям |

## Как устроено

```
App.tsx                 — навигация (нижние вкладки)
src/
  lib/                  — вся логика, без React: легко тестировать
    money.ts            — деньги в копейках, форматирование и разбор ввода
    paymentQr.ts        — сборка и разбор строки платёжного QR (ST00012|...)
    bank.ts             — операции над счетами (reducer), группировка, аналитика
    __tests__/          — тесты на node:test
  state/BankContext.tsx — React Context: хранит состояние, отдаёт run(action)
  screens/              — экраны
  components/           — переиспользуемые UI-компоненты
  data/mock.ts          — демо-данные
```

Решения, о которых стоит знать:

- **Деньги — целые копейки**, а не `number` с дробью: `0.1 + 0.2 !== 0.3`.
- **Логика отделена от UI.** Перевод — это чистая функция
  `bankReducer(state, action) → newState`, которая проверяет сумму, остаток
  и существование счетов и не мутирует исходное состояние. Экраны только
  вызывают `run(action)` и показывают ошибку, если она есть.
- **Формат QR** — ГОСТ Р 56042-2014: `ST00012|Name=…|PersonalAcc=…|BIC=…|Sum=…`.
  Символ `|` внутри значений заменяется, иначе строка сломается.
  Реквизиты проверяются (счёт — 20 цифр, БИК — 9).

## Запуск

Нужен Node.js 20+ и приложение **Expo Go** на телефоне.

```bash
npm install
npx expo install --fix   # подтянуть версии пакетов под текущий Expo SDK
npx expo start
```

Отсканируйте QR из терминала камерой телефона (iOS) или в Expo Go (Android).
Можно запустить и в эмуляторе: клавиши `a` (Android) / `i` (iOS).

## Тесты и проверки

```bash
npm test            # логика: деньги, платёжный QR, переводы
npm run typecheck   # TypeScript
```

## Что можно улучшить

- Сканирование QR камерой (`expo-camera`) вместо вставки строки.
- Сохранение состояния между запусками (`AsyncStorage`).
- Переводы по номеру телефона и подтверждение операций (Face ID / PIN).
- Тёмная тема и локализация.
- Компонентные тесты экранов (`@testing-library/react-native`).
